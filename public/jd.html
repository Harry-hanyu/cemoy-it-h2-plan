1岗位定位

小团队、共担结果，要求直接上手。

公司 IT 采用 1+1 配置。本岗位与 IT 负责人共同对交付结果负责，进组就能干活，能独立闭环，也能并肩联调。
Java 后端 Python 开发 前端 测试 数据开发 / 分析 轻量架构 项目管理

当前重点：财务与经营管理数据自动化（采集、清洗、核算、报表）、云端数据链路、业务系统 API 对接、RPA / 爬虫类自动化补齐等。

2工作职责

端到端参与，对结果负责。

  1. 后端开发：Java / Python 完成接口、服务、脚本与集成；对接金蝶、钉钉、聚水潭、领猫、电商开放平台等 API。
  2. 数据开发：参与 ODS → DWD → DWS / 天结果表分层；调度、清洗去重、维度关联、管理口径核算（分摊、成本、费用归因、预估等）。
  3. 数据分析支持：按财务 / 经营需求输出可核对明细与结果表；配合对账、验数、规则复算。
  4. 前端开发：内部工具、配置页、简单管理端或报表辅助页面；不追求纯视觉岗，要求独立交付可用界面。
  5. 测试与质量：自测、联调、回归；关键链路具备可复现校验（条数 / 金额勾稽、失败告警等）。
  6. 项目推进：拆任务、估时、跟风险；对齐财务 / 运营 / 供应链协作节点。
  7. 架构落地：在云服务器 / 云数据库 / 大数据计算体系上做可维护设计，避免不可运维的脚本堆砌。
  8. 自动化提效：参与 RPA / 爬虫采集（资金账单、店铺账单等），与影刀等工具配合，保障定时稳定跑数。
  9. AI 提效：熟练使用 Cursor、Codex 等工具，落到编码、测试与文档，保证质量门禁。

3任职要求

硬性门槛：精通两项 + 多域实战。

必须精通

  • Python：独立完成采集、清洗、服务 / 脚本、大数据相关开发与排错。
  • Java：真实项目后端经验；独立完成接口、服务、联调与定位（Spring 常见即可）。

优先加分

  • 用过 阿里云 DataWorks（调度、集成、MaxCompute / ODPS 等）。
  • 电商 / 零售 / 财务数据，或金蝶、钉钉、聚水潭对接经验。
  • 影刀 RPA / 爬虫生产运行；熟悉 RDS、ECS 等云产品。
  • 持续实践最新 AI 研发工具。

必须会（均需实战，非仅培训课）

  • 前端：至少一种主流框架或扎实 HTML/CSS/JS，能独立做出可用页面。
  • 后端：除 Java / Python 外，接触过 PHP 等更佳；理解 HTTP、鉴权、队列、定时任务。
  • 测试：自测用例 / 接口测试，能联调与回归。
  • 数据开发：理解 ODS/DWD/DWS 或同类分层，SQL 扎实；有调度、同步、清洗经验。
  • 数据分析：按业务口径出数、对差异、解释结果，不只是跑通 SQL。
  • 项目与架构：小团队拆任务、设计模块边界、评估技术债；有需求到上线完整交付经历。

4我们不适合谁

  • 只会单一技术栈，不愿碰数据或前端联调。
  • 需要长时间带教才能参与正式交付。
  • 只做需求翻译，不写代码、不背结果。
  • 简历很全，但说不清自己亲手上线过的项目细节。
到岗要求：直接上手实战，入职即可参与交付，不接受纯培养向。

5面试会重点看

  1. Python、Java 各讲一个 你本人主导 的项目：难点、解法、上线效果。
  2. 一条完整数据链路：从采集到清洗到结果表，你负责哪几段。
  3. 现场或作业：SQL / 小脚本 / 接口排错思路。
  4. 能否在一周内进入财务自动化相关任务并产出可验收结果。

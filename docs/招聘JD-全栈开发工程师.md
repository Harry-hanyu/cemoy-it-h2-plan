# 全栈开发工程师（综合技术向）

| 项 | 内容 |
|----|------|
| 岗位名称 | 全栈开发工程师 / 综合研发工程师 |
| 招聘人数 | 1 人 |
| 汇报对象 | IT 部门负责人 |
| 薪资范围 | 18K–20K（面议，按能力定级） |
| 工作地点 | 上海（具体办公点面试时确认） |
| 到岗要求 | **直接上手实战**，入职即可参与交付，不接受纯培养向 |

---

## 岗位定位

公司 IT 采用 **1+1** 精干配置。本岗位与 IT 负责人共同对结果负责，不是「只写某一端代码」的单一工种，而是：

**Java 后端 + Python 开发 + 前端 + 测试 + 数据开发 / 分析 + 轻量架构与项目管理** 的综合人才。

当前重点方向：财务与经营管理数据自动化（采集、清洗、核算、报表）、云端数据链路建设、业务系统 API 对接、RPA/爬虫类自动化补齐等。要求进组就能干活，能独立闭环，也能和负责人并肩联调。

---

## 工作职责

1. **后端开发**：用 Java / Python 完成业务接口、服务、脚本与集成；对接金蝶、钉钉、聚水潭、领猫、电商开放平台等 API。  
2. **数据开发**：参与 ODS → DWD → DWS / 天结果表等分层建设；调度任务、清洗去重、维度关联、管理口径核算（分摊、成本、费用归因、预估等）。  
3. **数据分析支持**：按财务 / 经营需求输出可核对的明细与结果表；配合对账、验数、规则复算。  
4. **前端开发**：按需完成内部工具、配置页、简单管理端或报表辅助页面（不追求纯视觉岗，要求能独立交付可用界面）。  
5. **测试与质量**：自测、联调、回归；关键链路要有可复现的校验方式（条数/金额勾稽、失败告警等）。  
6. **项目推进**：拆任务、估时、跟风险、对齐财务/运营/供应链协作节点；小团队内对交付结果负责。  
7. **架构落地**：在现有云服务器 / 云数据库 / 大数据计算体系上做可维护设计，避免一次性脚本堆成不可运维债务。  
8. **自动化提效**：参与 RPA / 爬虫类采集（如资金账单、店铺账单等无 API 场景），与影刀等工具配合，保障定时稳定跑数。  
9. **AI 提效**：熟练使用 Cursor、Codex 等 AI 编程工具，把 AI 落到日常编码、测试与文档，提升人效且保证质量门禁。

---

## 任职要求（硬性）

### 必须精通

- **Python 精通**：能独立完成数据采集、清洗、服务/脚本、与大数据作业相关的 Python 开发与排错。  
- **Java 精通**：有真实项目后端经验，能独立完成接口、服务、联调与问题定位（Spring 体系常见即可）。

### 必须会（均需有实战，非仅培训课）

- **前端**：至少一种主流框架或扎实的 HTML/CSS/JS，能独立做出可用页面。  
- **后端**：除 Java / Python 外，接触过 PHP 或其他后端语言更佳；理解 HTTP、鉴权、队列、定时任务等常识。  
- **测试**：会写自测用例 / 接口测试，能做联调与回归，不把问题甩给别人。  
- **数据开发**：理解数仓分层（ODS/DWD/DWS 或同类）、SQL 扎实；有调度、同步、清洗经验。  
- **数据分析**：能按业务口径出数、对差异、解释结果，不只是「跑通 SQL」。  
- **项目与架构**：能在小团队中拆解任务、设计模块边界、评估技术债；有过从需求到上线的完整交付经历。

### 优先加分

- 用过 **阿里云 DataWorks**（调度、数据集成、MaxCompute/ODPS 或同类大数据计算）。  
- 有电商 / 零售 / 财务相关数据或 ERP（金蝶等）、钉钉 OA、聚水潭等对接经验。  
- 有 RPA（如影刀）或爬虫稳定生产运行经验。  
- 熟悉云数据库 RDS、ECS、对象存储等常见云产品。  
- 持续关注并实践最新 AI 研发工具。

---

## 我们不适合谁

- 只会单一技术栈、不愿碰数据或前端联调。  
- 需要长时间带教才能参与正式交付。  
- 只做需求翻译、不写代码、不背结果。  
- 简历很全、但说不清自己亲手上线过的项目细节。

---

## 面试会重点看

1. Python、Java 各讲一个**你本人主导**的项目：难点、你怎么解决、上线效果。  
2. 一条完整数据链路：从采集到清洗到结果表，你负责哪几段。  
3. 现场或作业：SQL / 小脚本 / 接口排错思路。  
4. 能否在一周内进入现有财务自动化相关任务并产出可验收结果。

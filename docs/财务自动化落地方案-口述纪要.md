## 一、阶段目标总览

| 阶段 | 时间 | 核心思路 | 主流程 | 目标形态 |
|------|------|----------|--------|----------|
| 前三个月 | M1–M3 | **提升人效** | **当前主流程不变** | 用 RPA / 半人工 / 已接通 API + 云仓，把收集与初加工效率提上来 |

## 二、18 号出管理报表的根因与两大技术路径

现状约 **每月 18 号** 出管理报表，原因拆为两类，技术路线一一对应：

| # | 根因 | 主要表现 | 技术方案 |
|---|------|----------|----------|
| 1 | **数据收集工作量大** | 多账户/多系统人工拉取 | **RPA** |
| 2 | **数据计算处理成管理报表难** | 见下方明细 | **云数据仓库**（企业云数仓 / 数据中台分层） |

### 根因 2 的问题清单（计算与管理报表侧）

- 大量 **本地数据处理**
- **人工核算** 工作量大
- **二次加工 / 清洗** 数据
- **复杂计算规则与准确性**：科学分摊规则、加权成本、费用归因规则等
- **口径统一** 所对应的业务流程规范
- 规范数据所依赖的 **OA 等系统完善**
- 子方案：**人工预估报表 → 系统自动预估**
- 子方案：**资金流水与业务对账**
- （其他同类问题可继续追加）

## 三、公共底座（各导出线共用）

### 3.1 分层与维度

- 采集结果进入 **云数据集 / 企业云数仓**
- 分层：`ODS`（原始，允许重复）→ `DWD`（明细，合并清洗去重）→ 需要时 `DWS` / 结果天表
- `DWD` 挂接 **DIM 维度**（品牌、币种等后续计算必要维度）
- 建立 **管理报表所需公共维度表（DIM）**
- 维度数据源定时集成：**金蝶 API、钉钉 API、聚水潭 API、领猫 API** → 云仓 → 按管理口径自动计算为公共 DIM

### 3.2 采集手段组合

- **RPA**：无可用 API 或人工步骤明确可脚本化时（本机房台式机 + RPA 工具定时跑）
- **开放平台 / 业务系统 API**：有接口则优先 API 直连云仓
- **半人工**：过渡期（尤其前三个月）可接受

## 四、数据导出类子方案

### 4.1 资金账单

| 项 | 内容 |
|----|------|
| 现状问题 | **200+ 账户** 数据获取依赖人工拉取 |
| 推进方式 | 先 **评估出纳实际操作步骤**；若无更好 API 获取方式 → 本地机房准备台式机，安装 RPA，把人工步骤改为 **定时自动执行** |
| 落地节奏 | 执行完成后数据 **自动丢入云数据集**；建议 **每天凌晨** 执行；**允许重复数据** |
| 仓内处理 | Python 合并 / 清洗 / 去重：`ODS` → `DWD`；明细层挂 DIM（品牌、币种等） |
| 维度 | 与公共 DIM 建设打通（金蝶 / 钉钉 / 聚水潭 / 领猫 API） |

### 4.2 费用审批单

| 项 | 内容 |
|----|------|
| 获取 | **钉钉 API** 拉审批单（思路同资金账单的集成清洗） |
| 前三个月 | 做成数据集成 + 清洗 + 结果表输出（`ODS` → `DWD`） |
| 关键约束 | 必须解决当前 **费用归属** 不清的问题 |
| 审批流过渡（M1–M3） | **改造审批流之前**：要求业务人工 **准确选择** 归属等信息；财务 **严格审核** 准确性 |
| 半年度展望（约 6 个月） | 评估是否采用 **自研 + 外采「资金清分平台」**；未来规划含：**自动生成凭证**、**资金清分** |

### 4.3 销售 + 库存

| 阶段 | 内容 |
|------|------|
| 前三个月 | **半人工** 提效；手段组合：**RPA + API + 企业云数仓** |
| 半年度 | 解决 **跨境进销存数据打通**；跨境平台 API **定时接入** 企业云数仓；经数据中台 `ODS → DWD → DWS` **分层输出天表** |

### 4.4 店铺账单

| 阶段 | 内容 |
|------|------|
| 前三个月 | **RPA** 提效 |
| 半年度 | 打通 **API 自动进入** 企业云数仓 |

### 4.5 资金结余

| 阶段 | 内容 |
|------|------|
| 前三个月 | **评估是否需要自动化**；若不影响报表产出 → **继续人工** |
| 半年度 | 评估是否采用 **外采资金清分平台** |

> 「泗洪人工」为口误，已更正为继续人工。领猫 = 公司现行采购系统。

| 域 | 要求 |
|----|------|

- 货值与跨境进销存半年度打通 → 支撑更完整的管理利润与经营融合

## 3. 业务硬规则（写代码必须跟 v3）

1. **贸易类型**：`批发 / 跨境`（不要再写「大贸」）。
2. **批发成本**：货在**批发仓出库完成**时点，用**移动加权**算采购单价；销售成本单价**按天、次日生效**（不是 15 天）。
3. **跨境成本**：内部供货价 ± 头程（分列）；单价同样按天次日生效。
4. **报表时间**：运营天表按**支付日**；财务天表按**发货日**；同源明细同时留创建/支付/发货/结算等时间戳。
5. **库存双视角**  
   - 批发：采购在途、在仓  
   - 跨境：在仓、采购在途（批发→跨境）；供应下单/生产/在仓/总备货（**供应=批发对渠道的供给**，不是外部供应商）  
   - 相关表：DWD06 / DWD07 / ADS02 等，见字典「规则确认 F」与 Q-26
6. **数据起算**：自 **2025-01-01** 起进仓、算成本加权与期初库存。
7. 供货价改价：必须 **价格 + 填写日期 + 生效开始 + 填写人**，禁止只改价、禁止覆盖历史行。
